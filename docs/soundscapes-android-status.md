# Soundscapes Android Status

Ниже подробно описано, что уже реализовано в Android-модуле `soundscapes` на текущий момент.

## Архитектура и навигация

- Маршруты soundscapes заведены в навигации:
  - общий экран soundscapes,
  - экран конкретной сцены,
  - экран конкретного плейлиста.
- Переходы между экранами идут через side effects из ViewModel (Orbit MVI), а не напрямую из UI.
- Есть отдельные ViewModel под основные экраны:
  - `SoundscapesViewModel` (каталог),
  - `SoundscapePlaylistViewModel` (детали плейлиста),
  - `SoundscapeSceneViewModel` (плеер/редактор сцены).

## Данные и синхронизация с API

- В `EuforiaApi` есть рабочие методы для soundscapes-домена:
  - категории сцен,
  - список сцен и сцена по id,
  - плейлисты и плейлист по id,
  - звуки, музыка и категории (для picker'ов в сцене).
- В `SoundscapesRepository` реализованы:
  - синк каталога (категории + сцены + плейлисты),
  - синк звукового каталога,
  - получение деталей сцены,
  - получение деталей плейлиста.
- Данные сохраняются в Room-таблицы, и UI подписывается на `Flow` из DAO.
- По плейлистам уже учтена новая модель detail-ответа (`playlists/{id}` с `scenes`):
  - сцены из ответа сохраняются в `scenes`,
  - `sceneIds` плейлиста формируются корректно,
  - экран плейлиста получает и показывает список сцен из БД.

## Локальная БД и состояние

- Для soundscapes есть сущности и DAO для:
  - сцен,
  - категорий сцен,
  - плейлистов,
  - звуков и категорий звуков,
  - локального состояния сцены (пользовательские правки),
  - пресетов,
  - загрузок (download items).
- Есть методы `upsert`, `deleteAllExcept`, выборки по id и потоковые выборки для реактивного UI.

## Экран каталога (SoundscapesScreen)

- Показывает:
  - категории со сценами,
  - отдельный блок/режим плейлистов,
  - поиск,
  - quick filters.
- Поддерживает открытие:
  - сцены,
  - плейлиста,
  - paywall (если сцена pro и пользователь не premium).
- Есть mini-player, который отображает текущее состояние воспроизведения.

## Экран плейлиста (SoundscapePlaylistScreen)

- Загружает детали плейлиста через `playlistId`.
- Показывает title плейлиста и список сцен.
- Тап по сцене открывает экран сцены.
- UI обновлен:
  - сцены в 2 колонки,
  - добавлен нижний отступ/safe area как на остальных экранах.

## Экран сцены (SoundscapeSceneScreen)

- Реализован иммерсивный экран:
  - background image/video,
  - верхняя панель с действиями (закрыть/share/save/download),
  - нижний блок управления воспроизведением,
  - floating sound buttons на канвасе.
- Есть интерактив:
  - выбор слоя по тапу,
  - drag-and-drop звуковых кнопок,
  - применение новых координат в state.
- Реализованы bottom sheet'ы:
  - настройки музыки,
  - выбор музыки,
  - выбор и добавление звуков,
  - редактирование конкретного sound layer (volume/delete).
- Есть auto-hide controls с возвратом по тапу (поведение оверлеев).

## Playback и аудио-логика

- `SoundscapePlaybackController` держит состояние воспроизведения:
  - текущая сцена,
  - список слоев,
  - play/pause,
  - громкости,
  - сопутствующие флаги.
- `SoundscapeSoundsManager` управляет рендером звуковых слоев (ExoPlayer по слоям).
- Для фонового видео/музыки используется отдельный UI-компонент фона сцены.
- Есть связка mini-player <- playback state, чтобы главный экран знал, что сейчас играет.

## Кастомизация и персистентность

- Можно менять громкость музыки и слоев.
- Можно добавлять/удалять звуки в сцене.
- Изменения по слоям и позициям сохраняются как локальное состояние сцены.
- Есть работа с пресетами:
  - сохранение,
  - чтение списка,
  - удаление.
- Есть каркас под загрузки сцен (статусы и очередь в БД).

## Общий вывод по готовности

- Базовый пользовательский флоу уже полноценный:
  - каталог -> плейлист/сцена -> воспроизведение -> кастомизация.
- Данные идут end-to-end:
  - API -> repository -> Room -> Flow -> Compose UI.
- Основные экраны и ключевые интеракции в модуле уже есть и работают в единой MVI-структуре.
